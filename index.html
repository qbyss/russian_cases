Case Endings Reference

Prepositional Case

Usage: о/об + Prep. (about, concerning)

  • Masculine: -е / -и (if stem ends in -ий, -ь)
  • Feminine: -е / -и (if stem ends in -ия, -ь)
  • Neuter: -е / -и (if stem ends in -ие)

Accusative Case

Usage: в/на + Acc. (to, into)

  • Masculine (inanimate): = Nominative
  • Masculine (animate): -а / -я
  • Feminine: -у / -ю
  • Neuter: = Nominative
