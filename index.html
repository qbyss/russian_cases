Case Endings Reference

Prepositional Case - Nouns

Usage: о/об + Prep. (about, concerning)

  • Masculine: -е / -и (if stem ends in -ий, -ь)
  • Feminine: -е / -и (if stem ends in -ия, -ь)
  • Neuter: -е / -и (if stem ends in -ие)

Prepositional Case - Adjectives

Usage: о/об + Prep.

  • Masculine: -ом / -ем (новый → новом)
  • Feminine: -ой / -ей (новая → новой)
  • Neuter: -ом / -ем (новое → новом)

Accusative Case - Nouns

Usage: в/на + Acc. (to, into)

  • Masculine (inanimate): = Nominative
  • Masculine (animate): -а / -я
  • Feminine: -у / -ю
  • Neuter: = Nominative

Accusative Case - Adjectives

Usage: в/на + Acc.

  • Masculine (inanimate): = Nominative (новый)
  • Masculine (animate): -ого / -его (нового)
  • Feminine: -ую / -юю (новая → новую)
  • Neuter: = Nominative (новое)
